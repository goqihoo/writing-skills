# Write Doc

Make one document help its primary reader understand, decide, act, verify, or find an answer.

## Workflow

1. Identify the primary reader, question, and action the document must enable. Treat a supplied writing sample as the strongest voice guide.
2. Read the target, verified sources, repository instructions, and healthy local examples. Preserve facts, links, decisions, scope, and established conventions.
3. Lock the artifact type, core question, reasoning path, outline, section responsibilities, and required material. Preserve a healthy existing structure unless the user asks to change it.
4. Read `../../methods/prose-quality.md` and apply its reader-flow pass and prose contract.
5. Read `../../methods/visual-production.md` when the user requests a visual or the document would otherwise force readers to reconstruct a central relationship. Create the visual inside this workflow when warranted.
6. Recheck the finished document against the locked artifact plan. Restore any changed fact, name, number, term, citation, qualification, requirement, decision, constraint, premise, or conclusion.
7. Verify the reader action, local links, artifact boundary, prose-quality checks, and any retained visual before delivery.

## Boundaries

- Own a general document or a dedicated prose revision or review when no more specific Artifact Skill owns the requested result.
- Let a more specific Artifact Skill own its genre, reasoning, facts, template, and completion contract; that skill applies the same Shared Methods directly.
- Preserve exact code, commands, formulas, schemas, diagram labels, structured data, quotations, and exact-format text.
- Route a request for another independently owned artifact to its Public Skill rather than absorbing its result.

## Completion

The work is complete when one reader task resolves through a clear path, facts and decisions remain intact, the document satisfies the shared prose-quality checks, any visual adds supported information, and the artifact's structure and ownership remain honest.
