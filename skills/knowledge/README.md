# Knowledge

Explicitly invoked skills for reusable Knowledge not tied to one company or project.

- [Structure Domain Docs](structure-domain-docs/SKILL.md) (`structure-domain-docs`) — Structure an accepted Domain Knowledge set.
- [Write Domain Doc](write-domain-doc/SKILL.md) (`write-domain-doc`) — Write one common Domain Knowledge document.
- [Write Knowledge](write-knowledge/SKILL.md) (`write-knowledge`) — Create durable concepts, mechanisms, methods, patterns, cases, and references.
- [Write Arch Knowledge](write-architecture-knowledge/SKILL.md) (`write-architecture-knowledge`) — Create reusable Architecture Knowledge without a company commitment.
