# Scribe 0.7.1

Scribe 0.7.1 moves all 23 Public Skills to the standard flat `skills/<skill-id>/SKILL.md` layout used for plugin discovery. Foundations, Knowledge, Product Documentation, Technical Documentation, and Visual remain catalog classifications documented in the root README and Ask Scribe; they are no longer intermediate filesystem directories.

Shared Methods move from `skills/methods/` to the root `methods/` directory so plugin scanners cannot mistake them for invocable skills. Existing `../../methods/...` references remain valid from every flat skill directory.

Claude Code loads the canonical flat skills directly. Codex installs the generated package under `plugins/scribe/`, which contains the same flat skills and Shared Methods while removing the Claude-specific `disable-model-invocation` field. Every generated `agents/openai.yaml` retains `policy.allow_implicit_invocation: false`.

No Skill ID or Skill Display Name changes in this release. Reinstall the Scribe plugin and start a new task so the client rebuilds its skill index.
