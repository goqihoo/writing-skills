# Scribe 0.9.0

Scribe 0.9.0 adds **Write Deck** (`write-deck`) as the general entry for audience-facing presentation manuscripts in Markdown. It supports business, product, technical, learning, planning, and mixed professional settings by deriving one communication job and cumulative narrative path rather than registering topic-based deck types.

Write Deck owns the slide sequence, titles, screen copy, speaker support, transitions, visual direction, and source traceability. Presentation manuscripts remain derived expressions: their sources continue to own company facts, product commitments, technical truth, project state, evidence, and decisions. This release does not create PowerPoint, Keynote, PDF, or another rendered presentation file.

The shared Prose Quality Method now states **Natural expression** explicitly. Write Doc, Write Deck, and every other Public Skill continue to use that one non-invocable method rather than defining competing prose contracts. Deck-specific guidance applies the common contract to audience-facing titles, screen copy, speaker support, and transitions.

Scribe now exposes exactly 24 independently invocable Public Skills.
