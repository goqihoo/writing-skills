# Scribe 0.7.0

Scribe 0.7.0 makes every Public Skill independently invocable and end-to-end for its core result. Cross-skill reasoning, documentation structure, prose quality, and visual production now live in non-invocable Shared Methods under `skills/methods/` and are applied internally.

## Invocation change

Use one Public Skill for one requested result. The former required multi-skill combinations are not compatibility interfaces.

| Previous required combination | Scribe 0.7.0 invocation |
| --- | --- |
| `$Structure Domain Docs $Reason Domain $Structure Docs` | `$Structure Domain Docs` |
| `$Write Domain Doc $Reason Domain` | `$Write Domain Doc` |
| `$Write Arch Knowledge $Reason Arch` | `$Write Arch Knowledge` |
| `$Structure Product Docs $Reason Product $Structure Docs` | `$Structure Product Docs` |
| `$Write Product Doc $Reason Product` | `$Write Product Doc` |
| `$Assess Product Lifecycle $Reason Product` | `$Assess Product Lifecycle` |
| `$Write Product Strategy $Reason Product` | `$Write Product Strategy` |
| `$Map Product Capabilities $Reason Product` | `$Map Product Capabilities` |
| `$Write Product Roadmap $Reason Product` | `$Write Product Roadmap` |
| `$Design Product Metrics $Reason Product` | `$Design Product Metrics` |
| `$Structure Tech Docs $Reason Tech Docs $Structure Docs` | `$Structure Tech Docs` |
| `$Write Tech Doc $Reason Tech Docs` | `$Write Tech Doc` |
| `$Write Tech Arch $Reason Tech Docs $Reason Arch` | `$Write Tech Arch` |

Multiple named skills now mean multiple independently requested results. Reason, Structure Docs, Write Doc, and Draw Diagram remain Public Skills for standalone goals; they are not dependencies of artifact or structure skills.

## Shared Methods

The release introduces seven internal methods:

- Domain Reasoning
- Product Reasoning
- Technical Reasoning
- Architecture Reasoning
- Documentation Structure
- Prose Quality
- Visual Production

Shared Methods have no Skill ID, display name, `SKILL.md`, or client metadata and do not appear in the public catalog.

## Workflow behavior

- Every human-readable Public Skill result applies Prose Quality proportionally.
- A Public Skill applies Visual Production internally when requested or materially needed.
- A skill may create a supporting Assessment Record internally when traceability is needed.
- Real evidence, approval, or ownership gaps may stop a workflow; a missing skill invocation may not.
- Ask Scribe and default prompts recommend a single end-to-end skill by default.

## Completion

Migration is complete when callers invoke only the owning Public Skill for each result and no integration relies on a former required combination.
