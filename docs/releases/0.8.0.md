# Scribe 0.8.0

Scribe 0.8.0 completes Technical Architecture ownership across Company, System, and Subsystem levels. **Write Tech Arch** owns company-level Technical Architecture, Product-System Map, and cross-System Architecture Topics. **Write Tech Doc** owns System Architecture and Subsystem Architecture. Domain, Application, Governance, and Runtime remain analysis views used as coverage checks rather than mandatory output sections.

Technical structure now treats Strategy, Architecture, Systems, and Governance as logical responsibilities expressed in the documentation set's language. Every Registered System has a System Responsibility README and a direct System Architecture entry. Architecture Decisions live at the narrowest governing Architecture Level.

Product and Technical Common Writers now use small per-Writer YAML Internal Document Type registries. The generated catalog documents 10 Product types, 2 company-architecture types, and 11 Technical types. Templates are optional and explicitly configured as fixed, sequence, or adaptive; compatible occasional documents use a Freeform Artifact fallback instead of expanding the registry prematurely.

No Public Skill ID or Skill Display Name changes in this release. Scribe still exposes exactly 23 independently invocable Public Skills.
