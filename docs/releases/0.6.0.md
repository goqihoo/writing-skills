# Scribe 0.6.0

Scribe 0.6.0 makes every exact Skill Display Name an invocation name alongside its canonical Skill ID. User-facing examples now prefer display names, while directories, frontmatter, manifests, and code retain Skill IDs.

## Display-name changes

| Previous display name | New display name | Skill ID |
| --- | --- | --- |
| Reason About Architecture | Reason Arch | `reason-architecture` |
| Reason About Domains | Reason Domain | `reason-domain` |
| Reason About Products | Reason Product | `reason-product` |
| Reason About Technical Documentation | Reason Tech Docs | `reason-technical` |
| Write Architecture Knowledge | Write Arch Knowledge | `write-architecture-knowledge` |
| Structure Technical Docs | Structure Tech Docs | `structure-technical-docs` |
| Write Technical Architecture | Write Tech Arch | `write-technical-architecture` |
| Write Technical Doc | Write Tech Doc | `write-technical-doc` |
| Draw Diagrams | Draw Diagram | `draw-diagram` |

The replaced display names are not compatibility aliases. Use the new exact display name or the canonical Skill ID.

## Skill ID change

`draw-diagrams` is replaced by `draw-diagram`. The old ID, directory, and invocation are not retained.

## Composition change

Write Doc (`write-doc`) remains available as a standalone skill or optional prose-quality pass. Other Scribe skills no longer require it in every human-readable document workflow.
