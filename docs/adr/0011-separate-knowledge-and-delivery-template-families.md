# Separate Knowledge and delivery template families

Template ownership and separate structural families are superseded by [ADR-0012](0012-share-architecture-templates-across-purposes.md). Artifact authorities and the Project delivery branch remain in effect.

The user-provided CEX reference demonstrates that Architecture Knowledge is a multi-view document system with distinct overviews, object details, governance/runtime topics and engineering strategies. Replace the generic Knowledge asset with a manifest of actual document scaffolds, retain shared reasoning and adaptation methods, and extend Write Tech Arch with a distinct Project delivery branch while keeping stable System/Subsystem/Component design in Write Tech Doc; no Public Skill is added or renamed.

This supersedes ADR-0010's single Knowledge template and exclusion of project Technical Design ownership, and the historical specification's exact two/eleven Technical registry counts. Preserve the Knowledge/Company/Project authority distinction and small evidence-backed registries: materialize only requested artifacts, preserve healthy knowledge topology, and organize delivery by object rather than requiring one document per view. Dedicated topic templates cost more maintenance but recover the distinct structures observed in the reference; data/integration extensions remain candidates until their structures are confirmed.
