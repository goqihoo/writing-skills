# Give Technical Architecture an adaptive template

Status: accepted for the requested skill correction, 2026-10-01.

Repeated company architecture drafts covered constraints and open questions but failed to communicate the overall system structure. Assign an adaptive template to the existing Technical Architecture type through its Writer registry. Require an overview-first reader check and independent delivery/decision status, without imposing a fixed chapter sequence, number of services, target-only view, or one-file policy.

This uses ADR-0008's optional template mechanism; it does not change the generic registry rules or System Architecture routing. The cost is maintaining one additional template and regenerating the catalog/package. Revisit if the template prevents accurate current-state work or unnecessarily expands narrow edits. Validate registry/template reachability, package consistency and a real document application; text checks alone do not establish writing quality.
